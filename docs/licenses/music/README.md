## Résultat de la recherche

- Arcadia, Dreamy Flashback, Bathed in the Light, Frozen Star et Impact Lento figurent dans
  le catalogue de l’auteur. Leur présence dans KSP ne les rend pas propriétaires de Squad.
  Les anciens fichiers provenant de la bande originale ont été remplacés par les MP3 originaux
  téléchargés chez l’auteur, avec leurs titres conservés.
- Aucune licence compatible n’a pu être établie pour le fichier « 23 Space Ambience 1.mp3 »
  provenant de KSP. Ce résultat ne prouve pas l’absence de toute autorisation possible ;
  en l’absence de preuve, ce fichier a été retiré de public/ et remplacé dans les menus
  par Floating Cities (synthétiseurs, atmosphère calme et futuriste).
- La documentation précédente qui qualifiait toutes les pistes de propriétaires a été corrigée.
- Les crédits sont accessibles dans Paramètres → Musique → Crédits des musiques.
- Aucun enregistrement n’a été modifié. Le lecteur applique seulement un volume et répète les morceaux.
- Les anciens MP3 restent éventuellement dans l’historique Git : ils ne sont plus présents dans
  le dossier publié. Cet audit ne couvre pas les autres assets du projet.

## Preuves conservées

- tracks.json : métadonnées officielles des six titres, URL de téléchargement, date, taille et SHA-256.
- catalog-page.html : copie de la page officielle, dont le modèle affiche la licence CC BY 4.0.
- faq.html : FAQ de l’auteur, notamment les crédits visibles dans les réglages d’un jeu.
- licenses.html : choix officiel des licences Creative Commons et licence payante sans attribution.
- cc-by-4.0.html : texte juridique de la licence, archivé depuis Creative Commons.
